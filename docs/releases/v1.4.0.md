# Tersh v1.4.0

Use one private device inventory across your terminals. Each registered machine
selects its own local identity. An unregistered computer can open the full
dashboard as an observer. The host table and SSH routes follow that viewpoint.
Run `tersh --c --list-hosts` to verify the result without starting probes.

## Installation and updates

Release archives are available for macOS Apple Silicon and Linux/WSL on x86-64
and ARM64. The unified installer chooses the platform and verifies the archive.
Interactive file and cluster workbenches check the official stable release in
the background. If an update is available, the dashboard shows a notice and the
program asks on exit. Enter declines. Use `tersh --check-update` for an explicit
check or `tersh --update` to update immediately after confirmation.

A fleet controller can deliver a verified release and the private inventory
over existing SSH routes. Offline bundles support devices the controller cannot
reach. Existing inventories are checked before replacement and backed up when
changed. See the [setup guide](https://github.com/QiushanHuang/Tersh/blob/v1.4.0/docs/shared-fleet.md).

## Workbench and dashboard

- Choose the overview, topology with trends, or full-width meters with `1`,
  `2` and `3`. Filter by device name, navigate through jump hosts, and inspect
  measured values and missing samples.
- Use the existing Ghostty background with distinct node outlines and charts.
  The macOS RAM estimate excludes file-backed pages and distinguishes legacy
  pressure readings from physical RAM usage.
- Filter files in the file list, page by visible rows and find actions by
  effective shortcut.
