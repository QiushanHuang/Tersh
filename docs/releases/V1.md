# Tersh V1

Release date: 2026-05-31

Tersh V1 is the first product baseline for the terminal file workbench and read-only cluster status dashboard. This release focuses on product clarity, narrow-screen usability, safer file preview, safer destructive operations, and more predictable multi-host refresh behavior.

## What Changed

- Product logic and UI: footers now change by mode, so normal browsing, preview, search, prompts, confirmation dialogs, help, cluster list, and cluster detail show the shortcuts that actually work in that state.
- Narrow-screen layout: compact footer and status variants keep essential actions and file-operation context visible on small terminals and mobile SSH clients.
- Preview controls: `j` / `k` and `PageUp` / `PageDown` now page-scroll, while arrow keys and `Ctrl+F` / `Ctrl+B` line-scroll.
- Safer preview: symlinks are not followed, directories and special files display safe messages, and preview rendering is capped by bytes, line length, and line count.
- Safer delete/trash: confirmation dialogs show target count and first target; guards reject root, home, work root, `.tersh-trash`, relative paths, and symlinked trash directories.
- Cluster stability: host inventory validation catches unsafe or malformed SSH fields, duplicate aliases, unresolved jump hosts, and control characters before probes run.
- Cluster performance: refresh starts at most 16 probes at once and rotates across hosts to avoid starving later hosts in large inventories.

## Problems Found And Fixes

- Problem: bottom shortcuts were global, causing prompt, help, preview, and cluster detail screens to advertise actions that were inactive. Fix: introduced mode-aware footer text and compact variants. Result: the visible shortcut contract now matches actual behavior.
- Problem: preview scroll keys mixed page and line movement. Fix: separated page-scroll and line-scroll keys and updated help text. Result: preview navigation is easier to learn and harder to misuse.
- Problem: small terminal widths could hide the most important action hints and selected/copy state. Fix: added compact footer/status rendering. Result: mobile and narrow SSH sessions keep actionable context.
- Problem: preview could treat symlinks or special files like normal files. Fix: added no-follow regular-file checks and safe messages for unsupported file types. Result: preview avoids surprising filesystem reads and blocking special files.
- Problem: destructive operations lacked enough confirmation context and could target unsafe locations. Fix: added target context and path guards for root, home, work root, trash internals, relative paths, and symlinked trash directories. Result: accidental high-impact operations are rejected before execution.
- Problem: cluster refresh could start too many probes at once and inventory data could build unsafe SSH arguments. Fix: added validation plus capped, rotating refresh batches. Result: large inventories are more stable and invalid configs fail early.

## Notes

- Remote `t` mode still expects `tersh` to be installed and available in `PATH` on the selected remote host.
- `s` opens a local shell or interactive SSH session and returns to the dashboard after `exit` or `Ctrl+D`.
- `t` opens the Tersh workbench on the selected host and returns to the dashboard when the inner workbench exits.

## 中文说明

Tersh V1 是终端文件工作台和只读多主机状态面板的第一个产品基线版本。本次重点是产品逻辑清晰度、窄屏可用性、文件预览安全性、删除/回收站防护，以及多主机刷新稳定性。

- 底部快捷键会随模式变化，只展示当前状态真正可用的操作。
- 窄屏和移动端终端增加紧凑 footer 与状态区，保留关键动作和文件操作上下文。
- 全文预览中 `j` / `k`、`PageUp` / `PageDown` 按页滚动，方向键和 `Ctrl+F` / `Ctrl+B` 按行滚动。
- 预览不跟随符号链接，目录和特殊文件只显示安全提示，并限制字节数、单行长度和总行数。
- 删除和回收站确认会展示目标数量与首个目标路径，并拒绝根目录、家目录、当前工作根目录、`.tersh-trash`、相对路径和符号链接回收站目录。
- 集群清单会提前校验非法 SSH 字段、重复 alias、无法解析的跳板机和控制字符。
- 集群刷新最多同时启动 16 个探测，并在主机列表中轮转，避免大清单一次性压满。
