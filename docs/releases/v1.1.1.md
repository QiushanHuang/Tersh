# Tersh v1.1.1

Release date: 2026-08-11

Tersh v1.1.1 is a trust-and-usability release for people who use a terminal file
workbench locally or inside an SSH shell. It improves visual consistency,
narrow-screen usability, browsing performance, file-operation safety, and
cluster diagnostics while keeping the product lightweight and keyboard-first.

## Download

- Asset: `tersh-v1.1.1-macos-arm64.tar.gz`
- SHA-256: `9c34ad20801b9d54b5933422d148eb24281b0013ac0b658a8d8bb2ae846880e2`
- Platform: macOS on Apple Silicon (`arm64`)

The binary asset is intentionally distributed without Apple code signing or
notarization. Apple Gatekeeper validation was not used as a release gate. The
source tag, asset checksum, and repository verification results remain
available for independent inspection.

Extract and install the binary in a directory on `PATH`:

```bash
tar -xzf tersh-v1.1.1-macos-arm64.tar.gz
install -m 755 tersh "$HOME/.local/bin/tersh"
```

## What Changed

### A clearer and more adaptable interface

- Added btop, aurora, high-contrast, and no-color themes.
- Added ASCII, rounded, and thick border options.
- Added automatic, compact, and full shortcut-footer modes.
- Unified active/inactive panels, status chips, selected rows, warnings, and
  resource bars across the file workbench and cluster dashboard.
- Kept important selection and copy/cut state visible on narrow terminals.

### Faster everyday browsing

- Repaint only when input, resize, refresh, or data changes require it.
- Cache multiple recent previews within a fixed budget instead of retaining one
  preview or endlessly growing memory.
- Cache lowercase file names for repeated filtering and sorting.
- Filter the current in-memory directory listing instead of rescanning the
  directory for every typed character.

### Safer file workflows

- Added explicit `replace` / `skip` confirmation when copy targets already exist.
- Added direct file startup with `tersh <file>`.
- Recheck file identity before delayed copy, cut, rename, trash, delete, edit,
  and preview actions.
- Preserve existing targets until a replacement is ready and clean incomplete
  copy outputs after failure.
- Keep failed cut items in the transfer buffer so they can be retried.
- Revalidate ordinary files with no-follow behavior before editing or previewing.
- Continue rejecting filesystem roots, home/work roots, and Tersh trash paths
  from dangerous deletion flows.

### More reliable previews and terminal recovery

- Detect control bytes beyond the initial preview window.
- Invalidate stale previews using the visible preview range rather than only the
  first 4 KiB.
- Attempt bounded reads for virtual regular files that report a size of zero.
- Escape control characters and truncate wide Unicode names by terminal display
  width.
- Restore alternate-screen and raw terminal state consistently after editor or
  terminal-suspension failures.
- Reject oversized OSC52 clipboard payloads before writing terminal sequences.

### Safer cluster checks

- Added the clearer `--cluster` option while preserving `--c`.
- Added next-action hints for online, stale, authentication-failed, timed-out,
  and unknown hosts.
- Added actionable diagnostics for missing remote Tersh binaries and invalid
  remote working directories.
- Prevent stale or timed-out probe results from overwriting newer state.
- Bound probe output, clean timed-out process groups, preserve non-UTF-8 output
  lossily, and avoid login-shell startup files.
- Reject unknown inventory fields, duplicate or malformed SSH values, unresolved
  jump hosts, whitespace-bearing targets, and control characters.
- Require known SSH host keys during read-only health checks.

### Release and internal quality

- Updated the development release to 1.1.1 and the source MSRV to Rust 1.88.
- Build and install from locked dependencies; release builds use stripping and
  thin LTO.
- Added exact test selection and stricter test-output validation.
- Added repository-side append-only evidence, authenticated capture, retry,
  failure-preservation, and projection-repair reference coverage.

The evidence client and reference model are repository-side quality controls.
They do not claim that a production privileged Host service or custom CI runner
has been deployed.

## Important Fixes

- Prevented invalid sources from deleting an existing copy target before source
  validation succeeds.
- Prevented replace-copy from recursively removing an existing directory.
- Removed partial copy targets after regular-file or directory copy failure.
- Prevented stale path selections from acting on a replacement file.
- Prevented old cluster probe generations from overwriting newer timeout/stale
  state or resetting refresh timing incorrectly.
- Prevented transient directory-entry failures from clearing the full view.
- Fixed named `~user` expansion, late preview changes, virtual zero-size file
  previews, Unicode row truncation, and terminal restoration after editor errors.
- Fixed an integration issue where isolated evidence tools could replace a
  shared in-process core module and make later behavior depend on test order.

## 中文说明

Tersh v1.1.1 是一次以“更可信、更顺手”为重点的产品质量更新，面向在本地终端
或 SSH Shell 中管理文件的用户。

主要更新包括：

- 新增多种主题、边框和窄屏快捷键布局。
- 复制冲突提供明确的替换或跳过选择。
- 支持 `tersh <文件>` 直接定位并预览文件。
- 减少空闲重绘，增加多文件预览缓存和更轻量的筛选/排序。
- 文件操作执行前重新确认目标身份，降低目标被替换、误覆盖和残留半成品的风险。
- 修复剪切失败项目丢失、预览缓存过期、Unicode 截断和终端恢复问题。
- 加强服务器清单校验、SSH 检查边界、超时清理和旧结果隔离。
- 增加仓库侧精确测试和结果追踪能力，避免测试空跑、记录重复和失败历史丢失。

本版本提供未签名、未公证的 macOS Apple Silicon 二进制。Apple 签名、公证和
Gatekeeper 验证未作为发布阻塞条件；用户可以通过公开源码、版本标签和 SHA-256
自行核对发布内容。
