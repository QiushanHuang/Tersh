# Tersh v1.2.0

Release date: 2026-09-20

Tersh v1.2.0 brings cancellable file work, persistent trash recovery, configurable
controls and a more useful host dashboard to the lightweight terminal workbench.
It includes the existing v1.1.1 safety fixes and contribution history.

## Highlights

- **Work while a file job runs.** Copy, move, trash, delete and restore use one
  background worker. `J` shows progress and results; Ctrl+X requests cancellation.
- **Recover after restarting.** `u` opens managed trash records. Restore confirms
  the original location, rechecks identity and never overwrites an existing path.
- **Find the right host.** Filter by alias/address/role with `/`, cycle sort with
  `v` and reverse with `V`. Selection follows the host alias; probing still covers
  the configured inventory.
- **Use the keys that suit your device.** JSON bindings cover ten contexts,
  aliases and chords. `--dump-keymap` exports the effective map. Menus, help and
  footer hints display the actual bindings.
- **Discover actions with `o`.** Searchable menus expose file, preview, job,
  recovery and host actions without requiring shortcut memorization.
- **See changes over time.** Host detail keeps up to 60 observations for load,
  used memory, storage and complete probe duration, with gaps for missing data.
- **Adapt presentation.** Desktop/mobile/SSH presets, whole-key footer fitting,
  semantic color, no-color mode, optional Unicode trends and activity-only motion.

## Reliability

- Preserve delayed source/target identity checks through worker execution.
- Keep replacement originals until staging completes; refuse directory replacement.
- Preserve a new cut buffer when an older move completes at the same source path.
- Clean incomplete copies without following concurrently replaced directory links.
- Keep probe deadlines and owned resource lifetimes bounded even when descendants
  retain stdout/stderr pipes.
- Keep valid recovery records available when another receipt is malformed.
- Preserve printable text after a failed configurable chord and keep narrow
  restore confirmations focused on the actual target.

## Install

Release archives contain `tersh`, `LICENSE`, and `INSTALL.txt`. Check the matching
`.sha256` file before installing. Available builds:

| Platform | Archive |
| --- | --- |
| macOS Apple Silicon | `tersh-v1.2.0-macos-arm64.tar.gz` |
| Linux x86_64, static musl | `tersh-v1.2.0-linux-x86_64.tar.gz` |
| Linux ARM64, static musl | `tersh-v1.2.0-linux-arm64.tar.gz` |

macOS archives are not Developer ID signed or notarized. Linux builds include
their musl runtime. Source builds require Rust 1.88 or newer:

```sh
cargo install --locked --git https://github.com/QiushanHuang/Tersh.git --tag v1.2.0 --bin tersh --force
```

## Compatibility notes

Default keys remain familiar. Overrides replace an action's old shortcuts;
Ctrl+C remains reserved for safe exit. During file work, exit requests cancellation
and waits for cleanup. Cancellation retains completed work and cannot undo
permanent deletion or interrupt blocked filesystem calls.

Managed recovery requires same-filesystem rename and recorded UTF-8 paths.
Legacy trash remains untouched. Directory listing and preview loading remain
synchronous. Host history is memory-only; load is not CPU percent and probe
duration is not network RTT.

## Documentation and attribution

The README is now a shorter English guide with a dedicated Chinese edition,
screenshots and focused configuration documentation. Contribution guidance and
`.mailmap` preserve the maintainer's verified identity and historical authors.
The existing MIT copyright notice remains unchanged.

Verification covers Rust formatting, Clippy, all-target tests, Python reference
tests, native terminal workflows and the release build matrix. CI runs against
Rust 1.88 on macOS and Linux and packages each release architecture.
