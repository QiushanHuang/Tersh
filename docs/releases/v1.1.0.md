# Tersh v1.1.0

Release date: 2026-05-31

Tersh v1.1.0 is a small product-quality release focused on a denser btop-inspired terminal interface, safer editing and deletion flows, and clearer cluster health scanning.

## Asset

- `tersh-v1.1.0-macos-arm64.tar.gz`
- SHA-256: `59805543c90fcd57432b2a516e6fa273527516e2a44209d1466852b3da9bc559`

## What Changed

- Added a btop-inspired file workbench header with cwd, item count, selected size, buffer state, hidden-file state, filter text, and sort mode.
- Added sortable file browsing: press `s` to cycle sort modes and `S` to reverse the current sort.
- Reworked file rows into a compact operational table with selection, kind, permission, size, and name columns.
- Reworked the side pane into an Inspector with target, buffer, search/sort, and log sections.
- Reworked the cluster dashboard header into colored `OK`, `OLD`, `FAIL`, and `CHK` health tokens.
- Added per-host latency, memory, and disk columns to the cluster host list.
- Added `Esc` as a cancel key alongside `Ctrl+G`.
- Improved destructive-operation confirmation by showing whether targets come from the current focus or selection and listing the first affected paths.
- Escaped rendered paths and prompt input to prevent control-character pollution in terminal output.
- Editing now refuses symlinks and special files, and uses `$VISUAL`, `$EDITOR`, then `nano` fallback.
- Directory reloads now skip individual entries whose metadata disappears or cannot be read, instead of clearing the whole directory view.
- Declared Rust 1.85 as the minimum supported Rust version for this release.

## Problems Found And Fixes

- Problem: the file workbench had useful panels, but no single status strip for scan-critical state. Fix: added a high-density header. Result: path, selection, buffer, filter, hidden, and sort state are visible at all times.
- Problem: users could not sort files by size or modified time. Fix: added sort cycling and reverse sort commands. Result: remote triage can surface large or recently changed files quickly.
- Problem: the old info pane mixed metadata and logs without clear sections. Fix: split it into Inspector sections. Result: target, buffer, search/sort, and logs are easier to scan.
- Problem: cluster status counts were plain text and slow to read. Fix: changed them to colored health tokens and added mini metrics in the host list. Result: failures and stale hosts are easier to spot.
- Problem: only `Ctrl+G` cancelled prompts, which is awkward in many mobile SSH clients. Fix: added `Esc` cancel while preserving `Ctrl+G`. Result: modal exit is more predictable.
- Problem: paths and prompt input could render raw control characters. Fix: route display text through escaping helpers. Result: unusual file names cannot inject terminal control text into the UI.
- Problem: edit followed symlink behavior that preview intentionally avoided. Fix: restrict edit to regular files. Result: edit safety now matches preview safety.
- Problem: one disappearing directory entry could make reload clear the whole view. Fix: skip failed entries during listing. Result: directories on busy or remote filesystems stay usable.

## 中文说明

Tersh v1.1.0 是一次小版本产品质量更新，重点是更接近 btop 的高密度终端界面、更安全的编辑/删除流程，以及更清晰的集群健康扫读。

- 新增顶部状态栏，展示 cwd、条目数量、已选大小、缓冲区、隐藏文件、筛选和排序状态。
- 新增 `s` 循环排序、`S` 反转排序。
- 文件行改为紧凑表格，展示选择状态、类型、权限、大小和名称。
- 侧边栏改为 Inspector，分块展示目标、缓冲区、搜索/排序和日志。
- 集群状态栏改为彩色 `OK`、`OLD`、`FAIL`、`CHK` 指标。
- 集群主机列表新增延迟、内存和磁盘列。
- 新增 `Esc` 作为取消键，并保留 `Ctrl+G`。
- 删除/回收站确认会显示目标来自焦点还是多选，并列出前几个受影响路径。
- 渲染路径和输入内容时会转义控制字符，避免污染终端显示。
- 编辑功能只允许普通文件，并按 `$VISUAL`、`$EDITOR`、`nano` 的顺序选择编辑器。
- 目录刷新遇到单个条目 metadata 失败时会跳过该条目，而不是清空整个视图。
- 本版本声明 Rust 1.85 为最低支持版本。
