# Tersh logo

The mark combines a folder-shaped terminal window, a `>` prompt and a cursor.
It represents file work in a shell, with cyan for the working surface and a
muted violet cursor accent. The geometric wordmark uses vector paths, so it
needs no external fonts. No scripts, animation or external resources are used.

- `tersh-mark.svg`: square emblem with its own dark background.
- `tersh-logo-light.svg`: horizontal wordmark for light backgrounds.
- `tersh-logo-dark.svg`: horizontal wordmark for dark backgrounds.

Keep the proportions and leave clear space around the mark. Use the light or
dark wordmark appropriate to its background. These assets are provided under the repository's existing MIT license.
